POS Lot Expiration Warning

POS Lot Expiration Warning is a lightweight Point of Sale module that warns cashiers when an expired lot or serial number is selected. It checks the selected lot's expiration date during the normal POS lot selection flow.

By default, Odoo allows expired lots to be selected in POS without a cashier warning.

This module keeps the sale non-blocking and simply displays an acknowledgement popup with the product, lot/serial number, and expiration date.

Cashiers can verify the selected lot before continuing, while managers can disable the warning per POS configuration when it is not required.

Overview & Features

Show a clear POS warning when a selected lot or serial number has an expiration date in the past.

Key Features:
Expired Lot Warning
  • Checks selected POS lots
  • Uses standard expiration date
  • Shows product and lot details
  • Cashier can proceed after OK
POS Configuration
  • Per POS configuration toggle
  • Enabled by default
  • Available in POS settings
  • No extra setup model
Tracked Products
  • Works with lots
  • Works with serial numbers
  • Supports multiple selected lots
  • No payment flow impact

Installation

Ensure Odoo 18.0 is installed. No extra Python dependencies are required.

  • Dependencies: Standard point_of_sale and product_expiry modules are required.
  • Upload & Install: Upload the pos_lot_expiration_warning_cr folder to your Odoo addons path, update the apps list, and click Install.
  • Default Setting: The warning is enabled by default on POS configurations.

Configuration / Setup Guide

Configure the warning from Point of Sale settings. The setting is stored per POS configuration.

  • Open Settings: Go to Point of Sale > Configuration > Settings.
  • Select POS: Choose the POS configuration at the top of the settings page.
  • Enable Warning: Keep Lot Expiration Warning enabled.
  • Save: Save the settings and open the POS session.

Setup Steps

1. Enable Lot Expiration Warning

Enable the warning from Point of Sale settings for the required POS configuration.

2. Select an Expired Lot in POS

When the cashier selects an expired lot or serial number, POS shows a warning popup and lets the sale continue after acknowledgement.

Usage

Once installed and configured, cashiers continue using the standard POS lot selection flow.

  • Add a tracked product to the POS order
  • Select or scan the lot/serial number
  • If the lot is expired, review the warning popup
  • Click OK to acknowledge and continue
  • Complete the order normally

Troubleshooting

  • No warning shown: Ensure the POS configuration has Lot Expiration Warning enabled.
  • No expiration date: Lots without an expiration date do not show a warning.
  • Lot not found: Manually created/new lot names cannot be checked until the lot exists in inventory.
  • POS not updated: Reload the POS session after changing the configuration.
